# `~/.claude` — Claude Code home directory

User-level configuration, custom skills, plugins and runtime state for Claude Code on this machine. Hand-edited files (`CLAUDE.md`, `settings.json`, `skills/`, `plans/`) are small and valuable; everything else is generated by Claude Code and can mostly be regenerated.

**Stack:** Claude Code CLI / VS Code extension (v2.1.308), Python + `uv` skill scripts, JSON/JSONL state files, shell hooks.
